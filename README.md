# Taiwan Stock Trading & Screening System (twstock 驅動)

採用 Python `twstock` 套件整合真實台股資料，具備大盤儀表板、代號/股名雙向辨識、自選股群組、歷年股利及多週期區間選股系統。

## 特色功能
1. **twstock 深度串接**：
   - 內建上市櫃完整代號字典，輸入 `00878` 自動顯示 `國泰永續高股息 (00878)`。
   - 支援名稱搜尋，輸入 `三集瑞` 自動匹配 `三集瑞-KY (6862)`。
2. **固定不可刪除大盤**：主頁固定置頂加權指數（TAIEX）即時走勢，透過 WebSocket 自動推播。
3. **價位區間看漲推薦**：輸入最低價與最高價，系統自動利用日/月/季均線篩選出具看漲評分的標的。
4. **歷年股利與多週期診斷**：支援點擊查看個股歷年現金與股票股利、殖利率與短中長線趨勢。
