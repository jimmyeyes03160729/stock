# 📈 台股智慧戰情與全市場量化推薦系統 (v1.02)

一個整合 **TradingView Lightweight Charts**、**深度學習 CNN-5 圖像化時間序列分析**、**近 15 日三大法人籌碼追蹤** 與 **Firebase 雲端自選股同步** 的全方位台股即時監控與選股系統。

零伺服器成本運行，支援 GitHub Pages 純前端靜態部署，並能透過 GitHub Actions 每日自動化進行模型推論與數據校準。

---

## 🌟 核心功能亮點

### 1. 🤖 CNN-5 影像時間序列量化模型 (FinLab 實測落地)
* **特徵編碼 (Image Encoding)**：將股票近 5 日之開高低收 (OHLC) 與成交量 (Volume) Min-Max 正規化為 $60 \times 30$ 二值化黑白矩陣，消除絕對價格差距。
* **四大特徵模型切換 (I5/R5 系列)**：
  * `I5/R5`：純 K 線特徵 (w/o VB, w/o MA)
  * `I5/R5-m`：K 線 + MA 均線 (w/o VB, w/ MA) —— **夏普比率 1.6 最優**
  * `I5/R5-v`：K 線 + 成交量柱狀 (w/ VB, w/o MA) —— **年化報酬 33.90% 最佳**
  * `I5/R5-mv`：完整特徵矩陣 (w/ VB, w/ MA)
* **2012～2023 回測實證成果**：
  * **超級績效台股版 (VIP)**：導入 `finlab_cnn_factor` 排序後，年化報酬從 **33.91% 躍升至 42.32%**（MDD 改善 3.6%）。
  * **三頻率 RSI 策略**：買進前 10 檔年化報酬自 **22.96% 提升至 33.90%**。
  * **二次創高策略**：年化報酬由 **25.12% 提升至 31.41%**。

### 2. 🏛️ 近 15 日三大法人籌碼共振分析
* 拋棄傳統落後的股利靜態分析，全面實裝外資、投信、自營商近 15 個交易日每日買賣超數據明細。
* 只有當 **CNN 預測因子 ($P_{up} \ge 0.60$)** 與 **三大法人連續吸籌 (+張數)** 同步共振時，才觸發「強勢建議買」購買提醒。

### 3. 🎯 全市場 2,000+ 檔標的覆蓋與 ETF 獨立分離
* 修正過去流水號假代號問題，採用台灣證券交易所與櫃買中心之真實上市櫃個股（如飛宏 2457、三集瑞 6862 等）。
* 將 ETF（如 00878、0050、00919）獨立標記分類，在進行個股價格區間篩選時自動排除 ETF，聚焦高動能純個股。

### 4. 📊 專業走勢圖表與開盤狀態判定
* **TradingView Lightweight Charts**：點擊任一股票彈出專屬視窗，可查看長達 500 天的歷史日 K 線、20MA 月線與 60MA 季線。
* **智慧開盤判定**：自動判斷台股盤中時段（週一至週五 09:00～13:30），盤中維持 5 秒即時跳動；休市與盤後鎖定收盤價，不再胡亂跳動。

### 5. 🔐 欠款記帳系統共用帳號體系
* 透過 Firebase 實作自訂帳密登入與 Google 一鍵登入。
* 自選股群組可自由新增、自訂名稱，支援單檔個股 `✕` 刪除，並跨裝置即時雙向雲端同步。

## 🧭 系統介面說明

| 模組區塊 | 功能說明 |
| :--- | :--- |
| **加權指數 (TAIEX)** | 置頂鎖定大盤核心看板，盤中每 5 秒定時刷新，非交易時段顯示收盤點位。 |
| **CNN 模型切換欄** | 即時在 `I5/R5`、`I5/R5-m`、`I5/R5-v`、`I5/R5-mv` 間切換，動態調整因子靈敏度。 |
| **股價區間推薦篩選** | 輸入目標價位與多空條件（強勢建議買、中立觀望、弱勢建議空），即時產出 Top 排行。 |
| **AI 原理介紹彈窗** | 點擊頂部「💡 AI回測實證」，查看完整神經網路結構與 FinLab 實測表格。 |
| **歷年分析 Modal** | 包含 15 日法人每日張數表格、多週期趨勢診斷、TradingView 縮放走勢圖。 |

## 🛠️ 技術棧 (Tech Stack)

* **前端介面**：HTML5、Tailwind CSS (CDN)、TradingView Lightweight Charts v4.2.0
* **身分驗證 & 資料同步**：Firebase Authentication、Firebase Realtime Database
* **量化模型核心**：PyTorch (CNN_5_model)、NumPy、Pandas、FinLab API
* **自動化維護**：GitHub Actions (CI/CD)、GitHub Pages 靜態代管
